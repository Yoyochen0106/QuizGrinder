# 絕區零風：介面調查筆記

> 用途：skins/zzz.* 的設計依據。只取版面語言、配色、字體節奏、動態，不使用任何角色、吉祥物、標誌、專有名詞或素材。
> gcores 等網站在作業環境中無法直接開啟，只能讀到搜尋摘要；標「（自身知識）」的段落來自我對遊戲畫面的記憶。

## 來源摘要

- 探索在**一格格 CRT 電視組成的網格**上進行，玩家在電視之間移動小圖示；每台電視的畫面代表不同事件（例：綠色圖示＝回復、金幣＝貨幣）。（Digital Trends、Icy Veins、RPG Site 摘要）
- 早期試玩印象：**很「躁動」的 UI 元件、轉台式轉場、漫畫分格效果、故障（glitch）濾鏡**。（RPG Site、Geek Culture 摘要）
- 開發者訪談：都市題材仰賴大量招牌與廣告，**平面設計是重點**，例如街頭塗鴉。（dotgg Creator Notes 摘要）
- 美術取材 1980–90 年代都市街景、街機與小店。（分析文摘要）
- 中文設計評論：介面整體接近 App 的**深色模式**；中文字**超粗**，視覺衝擊強但長讀累眼；漫畫風分鏡、對話框與效果線提升演出。（gcores 184502 等摘要）——本實作因此**標題用超粗，內文維持正常粗細**。

## 字體節奏（自身知識）

- 英文：**超粗、窄、斜體**的無襯線大寫，常加黑色粗外框或位移陰影；數字斜體。
- 中文：極粗黑體；重點字放進黃底黑字的色塊。
- 常見「貼紙」：白邊、歪斜、帶硬陰影；膠帶條、塗鴉箭頭。

## 版面構圖（自身知識）

- 選單按鈕是**黑色粗外框的膠囊**，選中變黃；許多面板邊框帶硬陰影（無模糊）。
- 電視格探索：黑色空間中堆疊的電視，玩家所在格高亮；未探索格是雜訊／無訊號；畫面切換用**電視開關機（光線收成一條線再展開）**。
- 店面大廳：霓虹招牌、貨架、櫃台。

## 動態（自身知識）

- 轉台：螢幕縮成白線再展開、雜訊閃爍、VHS 追蹤線。
- 標題字偶爾有紅／青色偏移的故障抖動。
- 按鈕按下有位移與硬陰影縮短。

## 在 QuizGrinder 的對應

- 大廳＝店面櫃台：選主題「錄影帶」→ 開始探索。
- 每輪隨機產生 5×5 電視格：題目格、提示格（刪去一個錯誤選項）、情報格（看以前答錯的題目與正解）、出口。
- 開始探索與開題用「開機」轉場；未知格是動態雜訊與彩條；狀態訊息用漫畫對話框；計時用錄影時碼。
- 不使用任何角色、吉祥物或專有名詞（不稱「空洞」等）。
