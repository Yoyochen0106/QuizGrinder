# 重返未來：1999 風：介面調查筆記

> 用途：skins/r1999.* 的設計依據。只取版面語言、配色、字體節奏、動態，不使用任何角色、標誌、專有名詞或素材。
> 本次調查只有網路搜尋摘要可讀（WebFetch 被環境擋下）；標「（自身知識）」的段落來自我對遊戲畫面的記憶，未經本次來源核對。

## 整體印象

- 世界觀：1999 年最後一天的風暴把人類帶回 1920 年代，整體是西方復古風；有英、義、法等口音配音。（Steam 商店頁、gamequarter 摘要）
- 美術被形容為帶有超現實與 20 世紀末復古未來主義、手繪質感。（hyper3d 部落格摘要，品質普通）
- 1920 年代裝飾藝術（Art Deco）的特徵：對稱幾何、階梯形、金屬色點綴、高對比、裝飾性字體。（daisyui trends 摘要，一般風格資料）

## 卡牌合成機制（攻略摘要）

- 相鄰兩張相同的卡會合成升階：1 階＋1 階＝2 階，2 階＋2 階＝3 階（最高）。（talkandroid、hostedgg 摘要）
- 合成的觸發方式攻略說法不一（自動合成或拖曳消耗行動）；合成也會累積額外資源。→ 本風格用明確的「整理」按鈕觸發，且只合成「相鄰、同主題、同等級」。

## 字體節奏（自身知識）

- 標題為高對比襯線字（像報頭），標籤用打字機等寬字、全大寫、字距開；常見羅馬數字與票券編號。
- 選單像文件：剪報、郵戳、票根、打孔邊、雙線框。

## 動態（自身知識）

- 轉場：紙張翻頁、底片顆粒閃爍、光圈開合；卡牌合成時亮白閃光。

## 本風格的實作對應

- 首頁「題卡合成」：7 張依弱點主題抽出的題卡（主題配色，等級 I），「整理」讓相鄰同主題同等級合成升階（II、III），被合併題目回牌堆底；出牌＝作答，答對得等級 × 100；7 張後結算，最佳分數存 skinData.r1999。
- 「學習日報」報紙版面：報頭、期數（＝有作答的天數）、頭條、弱點專欄、簡訊、票根式最佳紀錄，全部來自真實紀錄。
- 舊紙顆粒、Art Deco 卡框、票根打孔、郵戳、底片顆粒閃爍與光圈進場。
