# 賽馬娘風：介面調查筆記

> 用途：skins/uma.* 的設計依據。只取版面語言、配色、字體節奏、動態，不使用任何角色、標誌、專有名詞（含能力名稱）或素材。
> game.watch 等網站在作業環境中無法直接開啟，只能讀到搜尋摘要；標「（自身知識）」的段落來自我對遊戲畫面的記憶。

## 育成畫面的資訊架構（來源摘要）

- 開發者講演整理：育成 UI 的目標是「正確呈現必要資訊，讓玩家不迷惘地選出下一步」。**頁首與頁尾幾乎固定**，畫面內容分成主資訊與副資訊，**主資訊放在手指搆得到的位置**。（game.watch 1366165 摘要）
- 從育成主畫面切到訓練選擇時，**基礎能力值固定顯示**，強化「正在培養」的意識。（同上）
- 攻略站描述：**體力條在畫面上方，是彩虹漸層**；**回合數是目標文字左邊的「日曆形狀」方塊**；**心情（狀態）顯示在體力條右邊**。（game8、umamusu.wiki 摘要）
- 心情共五段，影響訓練效率；能力共五項，最終依能力與技能給育成評價（G 到 SS 等級）。（game8、gamewith 摘要）

## 配色（近似值，自身知識）

| 用途 | 色 |
|---|---|
| 底 | 白 #ffffff、極淺灰綠 #f3f8f1，帶淡淡的格紋或圓點 |
| 主色（頁首、主按鈕） | 草地綠 #6cc04a – #3fa535，按鈕下緣有深一階的厚邊 |
| 比賽／重點 | 粉紅 #ff6aa8、橘 #ff9933 |
| 文字 | 深灰紫 #4a4458 而非純黑 |
| 體力條 | 藍→綠→黃→橘的彩虹漸層，外圍白框＋灰描邊 |
| 等級字母 | G 灰、F 藍、E 青、D 綠、C 黃綠、B 粉、A 橘紅、S 金；字母本身有漸層與白色粗外框 |

## 字體節奏（自身知識）

- 圓體感的粗黑字，數字特別粗大、常有白色外框與淡陰影。
- 英數小標用粗圓角無襯線；回合、倒數用大數字＋小單位字。

## 版面構圖（自身知識）

- 頂部：左邊日曆方塊（剩餘回合）、中間目標文字條、下方彩虹體力條、右邊心情（文字＋箭頭圖示，顏色依心情變化）。
- 中段：五項能力一列排開，每項是「彩色頭標＋大數字＋等級字母」。
- 底部：五個大圓形訓練按鈕，帶等級標示；選中時放大、彈跳。
- 主要按鈕是圓角膠囊，綠底白字，下緣深色厚邊；按下時下沉。
- 比賽結算：大型等級字母、閃光與緞帶。

## 動態（自身知識）

- 卡片與按鈕彈跳出現（overshoot）；選中項目輕微上下浮動。
- 換畫面時有斜向色塊掃過的轉場。
- 數值增加時數字跳動、浮出「＋」字樣。

## 在 QuizGrinder 的對應

- 頁首：日曆方塊（第 N 週）＋目標文字（目標考試與倒數）＋彩虹「今日訓練量」條＋心情（近 3 天正確率走勢）。
- 五項能力＝題數最多的 5 個主題分數；底部圓形訓練按鈕＝選主題練 10 題。
- 模擬考＝目標賽事；結果頁加上等級字母橫幅。
- 能力名稱、比賽名稱一律不照抄，改用主題名稱與「模擬考」。
