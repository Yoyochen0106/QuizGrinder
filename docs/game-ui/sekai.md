# Project SEKAI 風：介面調查筆記

> 用途：skins/sekai.* 的設計依據。只取版面語言、配色、字體節奏、動態，不使用任何角色、歌曲、標誌或素材。
> cgworld、gamer.ne.jp 等網站在作業環境中無法直接開啟，只能讀到搜尋摘要；標「（自身知識）」的段落來自我對遊戲畫面的記憶。

## 來源摘要

- 官方客服：曲目有 **EASY、NORMAL、HARD、EXPERT、MASTER** 五種難度；選曲畫面點 MASTER 圖示可看解鎖條件。（SEGA support）
- 判定分 Perfect、Great、Good、Bad、Miss；Good 以下會讓 Combo 歸零。判定線在畫面下方。（Bluestacks 攻略、Esteem Stream 摘要）
- 2023 年 9 月與 3 週年（2024）兩度大改 UI，讓介面更能感受到作品世界觀。（gamer.ne.jp、cgworld CEDEC 報導摘要）

## 配色（近似值，自身知識）

| 用途 | 色 |
|---|---|
| 主題色 | 青綠 #33ccbb 前後，搭配粉 #ff6699、紫 #8866ff、黃 #ffdd44 |
| 底 | 選曲是深色模糊背景＋白色半透明面板；遊玩畫面是暗色舞台 |
| 難度 | EASY 綠、NORMAL 藍、HARD 黃、EXPERT 紅、MASTER 紫（圓形難度鈕內是數字等級） |
| 判定 | PERFECT 為帶彩虹光澤的漸層字；GREAT 粉、GOOD 藍、MISS 灰 |

## 字體節奏（自身知識）

- 英文與分數用**粗、略斜的幾何無襯線**，分數 7 位數補零、字距略開。
- 「COMBO」小字在大數字下方；分數旁有 D→S 的評級刻度條逐步填滿。
- 中文用粗黑體，標籤常放進斜切的色塊。

## 版面構圖（自身知識）

- 選曲：左側大封面＋曲名＋難度鈕列＋最高分；右側縱向曲目清單，選中項放大並帶白框與發光。
- 遊玩：中央是透視往遠方收束的軌道，音符沿軌道落到判定線；左上分數條（含評級刻度）、右上生命值數字與條、右側大 Combo 數字；判定字在判定線上方彈出。
- 結算：大評級字母、分數、各判定數、最大 Combo、FULL COMBO／ALL PERFECT 標示。

## 動態（自身知識）

- 進入遊玩前有「LIVE START」類的轉場：斜向彩色色帶掃過。
- 判定字由大縮小彈入、短暫停留後淡出；Combo 數字每次增加時跳動。
- 背景有緩慢流動的光帶、三角形與閃光粒子。

## 在 QuizGrinder 的對應

- 曲目＝主題或考卷；難度依你在這組題目的正確率（越常答錯越難）。
- 每題 20 秒：作答秒數決定 PERFECT／GREAT／GOOD，答錯或逾時 MISS；Combo、生命條、分數評級刻度。
- 計時用透視軌道上落下的「音符」表示，抵達判定線即逾時。
- 不使用任何角色、歌曲名或專有名詞。
