# 明日方舟風：介面調查筆記

> 用途：skins/arknights.* 的設計依據。只取版面語言、配色、字體節奏、動態，不使用任何角色、標誌、專有名詞或素材。
> 本次調查時 gcores、game.watch 等網站在作業環境中無法直接開啟，只能讀到搜尋摘要；標「（自身知識）」的段落來自我對遊戲畫面的記憶，未經本次來源核對。

## 整體印象

- 公開分析一致指出：**層級對比度極高**；除了平面設計，還大量用**背景模糊**把需要操作的區塊推到前景，並搭配「符合世界觀的警戒亮色」。（gcores 112810 摘要）
- 騰訊遊戲學院〈UI/UX 分析——藏在好看背後的先進性〉從六個角度拆解：沉浸式主看板、類 Fluent Design 的多層質感、扁平介面中的空間深度、風格化裝飾字體、焦距與底圖處理、用過場銜接減少頁面層級。（163 轉載、gcores 123154 摘要）
- 有重製分析指出：介面以**黑白灰為主、輔以藍色與橙色**；圖形以矩形為主、少量圓形，部分區域有規則幾何的漸層底紋。（gcores 135723 摘要）

## 字體節奏（自身知識）

- 中文標題用很粗的黑體，常配一行**很小、全大寫、字距拉很開的英文副標**（例：中文「作戰」下方配英文小字）。
- 英文與數字用**幾何、略窄的科技感無襯線體**；大標題英文用**超寬、字距很大**的大寫字。
- 數字一律等寬、對齊；資源數值放在細框內，左邊配小圖示。
- 標題字有時用有質感的明體（思源宋體），內文用黑體。（gcores 135723 摘要）

## 主畫面構圖（自身知識）

- 右半部是**一組帶透視傾斜的大方塊選單**（整組像投影在玻璃上，略往畫面內轉），最大一塊是白底黑字的「作戰」入口，其餘是深灰小磚。
- 左上：玩家資訊；右上：資源列（細框、等寬數字）；左下：公告／好友等小入口。
- 面板常有**切角**、**角落括號**、**十字準星標記**、**細刻度線**、**條碼狀色塊**、**大字號背景編號**、斜線「///」、警示斜紋。
- 關卡地圖：深色網格背景，**長方形節點＋直角折線連接**，可左右捲動；選中後右側滑出簡報面板，大號關卡代號＋「開始行動」按鈕。
- 結算：深色畫面上大字「作戰完成」類橫幅，星數評價。

## 動態（自身知識）

- 面板**由右快速滑入、ease-out**，偶爾有短暫閃爍（掃描線、電子雜訊）。
- 讀取畫面：細長進度條＋小字代碼與提示。
- 主畫面隨裝置傾斜有視差。按鈕按下時有短促的亮框與位移。

## 在 QuizGrinder 的對應

- 首頁「作戰終端」：右側透視傾斜的選單方塊、左側關卡地圖與「基地」產能面板。
- 入場：一次性的「終端連線」讀取條；換頁：由右滑入＋短暫閃爍。
- 練習＝戰術簡報；模擬考結果＝「作戰結束」橫幅與三星（60／70／85 分）。
- 體力不照抄：只顯示「今日建議量 n／20」提醒。
