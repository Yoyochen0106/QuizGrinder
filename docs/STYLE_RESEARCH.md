# 版面風格調查：科技業、設計界、二次元手遊

版面實驗（`?skins`）候選清單。每一項列出該網站或遊戲最具代表性的介面與互動，以及套用到刷題的方案。

**實作原則**（同 [SKINS.md](SKINS.md)）：只借用版面、互動與配色。不使用標誌、角色、立繪、專屬字型與美術素材；數字都必須由真實學習紀錄計算。遊戲類方案的「抽卡」「體力」等機制只用來包裝學習進度，不涉及任何付費或隨機付費獎勵。

> 內容依撰寫時對這些產品的了解整理（研究環境無法連線查證），實作前建議再看一次實際畫面。

已完成的 26 種：YouTube、Google、Claude Docs、Instagram、Threads、Clash of Clans、Duolingo、Quizlet、Anki、Kahoot!、Wordle、Stack Overflow、TikTok、Netflix、Spotify、Reddit、Pinterest、LINE、Trello、Notion、GitHub、Google Sheets、Google 日曆、蝦皮、Apple 健身、Steam。

## 三、二次元手遊 20 個 UI/UX 方案

共同注意事項：
- **不用角色與美術**：不使用任何角色、立繪、Live2D、劇情文字或遊戲專有名詞。角色位置改用電路板元件擬人以外的原創圖形，例如晶片、焊墊、電路紋路。
- **不做付費抽獎**：「抽卡」只能用學習進度換取裝飾性獎勵，例如題卡外框或主題色，不能有付費或令人沉迷的隨機獎勵設計。
- **體力只當提醒**：「體力／理智」只能作為每日建議量的提醒，不限制使用者學習。

|---|---|---|---|

**優先推薦**：
- **明日方舟**：工業科技 UI 和 PCB 製程最搭。
- **賽馬娘育成**：直接對應「考前 N 週」的備考規劃。
- **Project SEKAI**：判定與 Combo 讓限時練習更有節奏感。
- **絕區零電視格**：版面最有辨識度。
